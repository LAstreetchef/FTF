Platform Overview

How Food Truck Fundraiser Works:
  1. Organizers create events by selecting food trucks, setting menu markups, and defining goals
  2. $1.95 organizer fee must be paid before events go public
  3. Supporters pledge for delicious menu items if the event reaches its funding goal
  4. Payments are charged only when events are fully funded
  5. Organizers earn markup profit and food trucks get their minimum guaranteed sales
  6. Community celebrates together with great food and successful fundraising!
Key Concept: This is conditional crowdfunding - money only moves when goals are met. Everyone wins when the community comes together!
📞 Support Response Times:
🚨 Urgent Issues:
Payment failures, event cancellations
Response: Within 4 hours
📧 General Support:
Account questions, general help
Response: Within 24 hours (business days)

Supporting Organizers

Common Organizer Issues:

Solution: Check if they paid the $1.95 organizer fee.
How to check: Go to Admin → Events, find their event, check "Organizer Fee Charged" column.
If unpaid: They can pay from their dashboard under "Payment Required" status.
Admin action: You can manually mark fee as paid if needed in event details.

Payout Process:
  1. Event must reach funding goal and be approved
  2. Organizer must complete payout setup (bank/PayPal)
  3. Admin processes payout from Admin → Events → "Process Payout"
Check payout status: Admin → Events → View event details → Payout section

Supporter Contact:
  • From organizer dashboard: Click "Supporters (X)" button
  • Shows supporter emails and pledge details
  • Built-in "Send Thank You" feature with email templates
  • Admin can also access this from Admin → Events → "Supporters"

Event Editing Limitations:
  • Before any pledges: Admin can edit most details
  • After pledges: Only basic info (description, date) to protect pledger agreements
  • Cannot change: Food truck, menu items, pricing, goals once pledges exist
Admin action: Edit from Admin → Events → Edit button

Gift Meal Feature:
  • Pledgers can purchase meals as gifts for others
  • Gift recipient gets separate email with e-ticket
  • Purchaser can include personal message
  • Both purchaser and recipient receive confirmation emails
  • Gift meals count toward event funding goals
Admin support: Check gift details in Admin → Events → View Pledges

Key Terms for Organizers:
  • Risk assumption: Organizers assume all event risks and responsibilities
  • Platform role: We're a technology platform, not event managers
  • No liability: Platform not responsible for event outcomes or disputes
  • Compliance: Organizers responsible for permits, taxes, insurance
  • Termination: Platform can suspend accounts for violations
Full terms: Available during organizer registration process

Supporting Food Trucks

Common Food Truck Issues:

Truck Approval Process:
  1. Food truck registers and pays $25 registration fee
  2. Admin reviews and approves truck
  3. Truck appears in organizer selection list
Check status: Admin → Food Trucks → Check "Status" and "Registration Fee Charged" columns
Admin action: Approve truck or mark registration fee as paid

Menu Management:
  • Food trucks manage menus from their dashboard
  • Can add/edit items before events use them
  • Cannot change items that are already in active events
Admin help: Admin → Food Trucks → Edit truck → Menu Items section

Food Truck Payment:
  • Payments processed after event completion
  • Food trucks receive their base menu prices (before markup)
  • Payments sent via established payout method
Check payout: Admin → Food Trucks → View payout history

Organizer Communication:
  • Organizer contact info shown in event details
  • Admin can facilitate contact if needed
  • Important to coordinate event logistics directly
  • Discuss setup time, location access, menu availability
Admin help: Can provide organizer contact details if requested

Last-Minute Cancellation Process:
  1. Contact support@foodtruckfundraiser.com immediately
  2. Admin will notify the organizer and all pledgers
  3. Event will be cancelled and pledges refunded
  4. Consider offering replacement date if possible
Important: Last-minute cancellations impact community trust. Always communicate as early as possible!

Payment Issues

Failed Pledge Payments:
  • Check Admin → Events → View pledges
  • Failed payments show "failed" status
  • Supporters can retry payment from their email
  • Admin can manually mark as paid if verified
Payout Issues:
  • Verify payout method is set up correctly
  • Check bank details or PayPal email accuracy
  • Ensure minimum thresholds are met
  • Review payout status in admin dashboard
Important: Always verify payment information before processing manual payouts. Document any manual interventions in the event notes.

Pledge Transfer System

How Pledge Transfers Work:
  1. Organizer initiates transfer from their dashboard using "Transfer" button
  2. Email sent to each pledger asking for consent to move their pledge
  3. Pledgers have 7 days to approve or decline via email links
  4. Approved pledges transfer to the target event automatically
  5. Declined/expired pledges remain with the original event

Troubleshooting Transfer Emails:
  • Check spam/junk folders first
  • Emails sent from support@foodtruckfundraiser.com
  • Admin can check transfer status: Admin → Events → View Transfers
  • Admin can resend transfer emails if needed
  • Transfer requests expire after 7 days

Transfer Requirements:
  • Same organizer: Can only transfer between events owned by same organizer
  • Event status: Source can be pending/funded/approved, target must be pending/funded
  • Pledge status: Only pending or charged pledges can transfer
  • Amount preservation: Pledge amounts remain the same
  • Menu differences: Pledgers will see new menu options in target event

Real-World Use Cases

Successful Examples to Share with Users:

Scenario: Parent organizes food truck lunch for school fundraiser
Strategy:
  • Choose popular truck (Pizza, Tacos, BBQ)
  • Set 25-30% markup on menu items
  • Target goal: $800-1200 for good profit
  • Share on school Facebook groups, parent emails
  • Emphasize convenience - pre-ordered, guaranteed delivery
Tips: Time events during lunch rush, coordinate with school calendar

Scenario: Office manager organizes team lunch
Strategy:
  • Select premium truck with healthy options
  • Set 15-20% markup (company budget friendly)
  • Higher goal: $1500-2000 for larger groups
  • Share via company Slack, email announcements
  • Coordinate timing with office location access
Tips: Plan 2-3 weeks ahead, confirm truck parking logistics

Scenario: Neighborhood association fundraiser
Strategy:
  • Choose family-friendly truck (ice cream, burgers)
  • Set 20-35% markup for fundraising goals
  • Target: $500-1000 depending on neighborhood size
  • Use Nextdoor, Facebook community groups
  • Plan for weekend timing when families available
Tips: Partner with local park or community center for location

Edge Cases & Troubleshooting

Payment Failure Process:
  1. System attempts to charge all pledges when event is funded
  2. Failed payments are marked as "failed" status
  3. Email sent to pledger with payment retry link
  4. Event may need to be re-evaluated if too many failures
Admin actions:
  • Check failure reason in Admin → Events → View Pledges
  • Contact pledger directly to resolve payment issue
  • Can manually retry payment once issue is resolved

Duplicate Pledge Resolution:
  • Check if both pledges are from same email/payment method
  • Contact user to confirm which pledge to keep
  • Admin can cancel one pledge before charging
  • If already charged, process refund for duplicate
Prevention: System should prevent obvious duplicates, but users may use different emails

Emergency Cancellation Process:
  1. Immediate action: Mark event as cancelled in admin
  2. Communication: Email all pledgers immediately
  3. Refunds: Process all refunds within 24 hours
  4. Food truck notification: Contact truck to confirm cancellation
  5. Documentation: Record reason for cancellation
Urgent situations: Weather, permit issues, truck breakdown, medical emergency

Technical Issues

Login Problems:
  • Verify correct email address
  • Check password requirements (6+ characters)
  • Clear browser cache and cookies
  • Try incognito/private browsing mode
Email Issues:
  • Check spam/junk folders
  • Whitelist support@foodtruckfundraiser.com
  • Admin can resend notifications manually
Payment Processing:
  • Stripe handles all payment processing
  • Failed payments usually due to insufficient funds or card issues
  • Admin can view detailed payment logs
  • Refunds processed automatically for cancelled events
Browser Compatibility:
  • Modern browsers recommended
  • JavaScript must be enabled
  • Mobile-friendly responsive design
