Platform Overview

How Food Truck Fundraiser Works:
  1. Organizers create events by selecting food trucks, setting menu markups, and defining goals
  2. $5 organizer fee must be paid before events go public
  3. Supporters pledge for menu items if the event reaches its funding goal
  4. Payments are charged only when events are fully funded
  5. Organizers earn markup profit and food trucks get their minimum guaranteed sales
Key Concept: This is conditional crowdfunding - money only moves when goals are met.

Supporting Organizers

Common Organizer Issues:

Solution: Check if they paid the $5 organizer fee.
How to check: Go to Admin → Events, find their event, check "Organizer Fee Charged" column.
If unpaid: They can pay from their dashboard under "Payment Required" status.
Admin action: You can manually mark fee as paid if needed in event details.

Payout Process:
  1. Event must reach funding goal and be approved
  2. Organizer must complete payout setup (bank/PayPal)
  3. Admin processes payout from Admin → Events → "Process Payout"
Check payout status: Admin → Events → View event details → Payout section

Supporter Contact:
  • From organizer dashboard: Click "Supporters (X)" button
  • Shows supporter emails and pledge details
  • Built-in "Send Thank You" feature with email templates
  • Admin can also access this from Admin → Events → "Supporters"

Event Editing Limitations:
  • Before any pledges: Admin can edit most details
  • After pledges: Only basic info (description, date) to protect pledger agreements
  • Cannot change: Food truck, menu items, pricing, goals once pledges exist
Admin action: Edit from Admin → Events → Edit button

Supporting Food Trucks

Common Food Truck Issues:

Truck Approval Process:
  1. Food truck registers and pays $25 registration fee
  2. Admin reviews and approves truck
  3. Truck appears in organizer selection list
Check status: Admin → Food Trucks → Check "Status" and "Registration Fee Charged" columns
Admin action: Approve truck or mark registration fee as paid

Menu Management:
  • Food trucks manage menus from their dashboard
  • Can add/edit items before events use them
  • Cannot change items that are already in active events
Admin help: Admin → Food Trucks → Edit truck → Menu Items section

Food Truck Payment:
  • Payments processed after event completion
  • Food trucks receive their base menu prices (before markup)
  • Payments sent via established payout method
Check payout: Admin → Food Trucks → View payout history

Payment Issues

Failed Pledge Payments:
  • Check Admin → Events → View pledges
  • Failed payments show "failed" status
  • Supporters can retry payment from their email
  • Admin can manually mark as paid if verified
Payout Issues:
  • Verify payout method is set up correctly
  • Check bank details or PayPal email accuracy
  • Ensure minimum thresholds are met
  • Review payout status in admin dashboard
Important: Always verify payment information before processing manual payouts. Document any manual interventions in the event notes.

Event Management

Event Lifecycle:
PENDING
Collecting pledges
FUNDED
Goal reached, payments processing
APPROVED
Event completed, payouts available
CANCELLED
Event cancelled, pledges refunded
Common Admin Actions:
  • Approve funded events: Admin → Events → "Approve" button
  • Cancel events: Admin → Events → "Cancel" (refunds all pledges)
  • Process payouts: Admin → Events → "Process Payout"
  • Contact supporters: Admin → Events → "Supporters" button

Technical Issues

Login Problems:
  • Verify correct email address
  • Check password requirements (6+ characters)
  • Clear browser cache and cookies
  • Try incognito/private browsing mode
Email Issues:
  • Check spam/junk folders
  • Whitelist support@foodtruckfundraiser.com
  • Admin can resend notifications manually
Payment Processing:
  • Stripe handles all payment processing
  • Failed payments usually due to insufficient funds or card issues
  • Admin can view detailed payment logs
  • Refunds processed automatically for cancelled events
Browser Compatibility:
  • Modern browsers recommended
  • JavaScript must be enabled
  • Mobile-friendly responsive design

Escalation Process

When to Escalate:
High Priority - Escalate Immediately:
  • Payment system errors
  • Security concerns
  • Legal/compliance issues
  • Data loss or corruption
Medium Priority - Escalate if Unresolved:
  • Complex payout issues
  • Event cancellation requests
  • Multiple failed attempts
  • Technical bugs
Escalation Contacts:
  • Technical Issues: Forward to development team
  • Payment Issues: Financial operations team
  • Legal Issues: Management
