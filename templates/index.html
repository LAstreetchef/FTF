Food Truck Fundraiser

Bringing communities together through crowdfunded food truck events. Support local events and enjoy amazing food!

Organizers can create events, communities can pledge for food tickets, and everyone wins when goals are met.

View Events Create Event

How It Works

1. Create an Event

Event organizers select a food truck, set menu items with markup pricing, and create their fundraising event.

2. Community Pledges

Community members pledge money for meal e-tickets. Payments are only charged if the funding goal is met.

3. Event Happens

When goals are met, pledges are charged, e-tickets are sent, and the food truck attends the event!
